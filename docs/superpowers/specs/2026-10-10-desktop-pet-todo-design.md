# 代办桌宠 · 设计规格

- 日期：2026-10-10
- 状态：已与用户确认设计，待审阅
- 平台：Windows（后续可扩展 macOS/Linux，Electron 天然跨平台）

## 1. 概述

一个明日方舟风格的桌面宠物：基建小人常驻桌面，**点击桌宠即可查看和管理待办清单**。支持截止提醒、番茄钟、情绪联动；可选接入 OpenAI 兼容大模型 API，实现对话和口语化创建待办。**离线时是功能完整的待办桌宠，在线是增强版。**

### 1.1 目标

- 桌宠形象为明日方舟干员基建小人（Spine 骨骼动画），兼容 Ark-Pets 模型包生态
- 单击桌宠弹出待办面板：分组展示（逾期/今天/无日期）、增删改查、勾选完成
- 截止时间提醒：系统通知 + 桌宠头顶气泡 + 特殊动作
- 番茄钟：专注/休息循环，桌宠状态跟随变化
- 情绪联动：桌宠心情随待办完成情况变化（动作、活跃度、台词）
- AI 增强（可选）：OpenAI 兼容 API，对话 + function calling 操作待办

### 1.2 非目标（本期不做）

- 多设备云同步
- 待办统计分析页（完成率图表等）
- 桌宠站在任意窗口边缘（v2 彩蛋，本期只做屏幕底部/任务栏站立）
- 音效/语音
- 移动端

## 2. 技术栈

| 层 | 选型 | 理由 |
|----|------|------|
| 框架 | Electron + electron-vite + React + TypeScript | Live2D/Spine 桌宠最成熟路线，透明窗口/托盘/通知 API 现成 |
| 动画渲染 | pixi.js v7 + pixi-spine（Spine 3.8 运行时） | 明日方舟模型为 Spine 3.8 格式，Chromium 兼容性最好 |
| 数据 | electron-store（JSON） | 待办量级小，简单可靠，免编译原生依赖 |
| 测试 | vitest | 逻辑层单测 |
| 包管理 | npm | 用户环境为 Windows，npm 零配置 |

## 3. 窗口与进程架构

### 3.1 Electron 主进程职责

- 窗口管理：桌宠窗口、待办面板窗口、设置窗口的创建/销毁/定位
- 托盘菜单：显示/隐藏桌宠、切换干员、打开待办/设置、退出
- 单实例锁（`app.requestSingleInstanceLock`）
- 通知调度：扫描待办截止时间，到点发 `Notification`
- 开机自启（`app.setLoginItemSettings`，设置里可开关）
- IPC：渲染层与主进程的命令通道（窗口控制、模型文件读写、通知）

### 3.2 桌宠窗口

- `frame: false`、`transparent: true`、`alwaysOnTop: true`、`skipTaskbar: true`、`resizable: false`
- **鼠标穿透**：调用 `setIgnoreMouseEvents(true, { forward: true })`（转发鼠标移动消息给渲染层）；渲染层监听 `mousemove` 用 pixi 命中检测角色包围盒，进入角色区域时通过 IPC 切回 `false`、离开时恢复穿透，实现"点得到角色、穿透空白区域"
- 尺寸跟随干员缩放设置；位置持久化（记住上次放置的屏幕坐标）

### 3.3 待办面板窗口

- 单击桌宠时在桌宠旁弹出（自动处理屏幕边缘翻转，防止超出屏幕）
- 普通样式小窗（约 360×480），可关闭；"固定"模式则常驻显示
- 关闭即隐藏（不销毁），下次点击秒开

### 3.4 设置窗口

- 普通 React 表单页：AI API 配置、干员管理（下载/导入/切换）、提醒偏好、番茄钟时长、开机自启、缩放/帧率

## 4. 动画引擎

### 4.1 模型来源与格式

- 兼容 **Ark-Pets 模型包**（zip：Spine 骨骼 json/skel + atlas + png 序列）
- 内置模型下载器：拉取 [Ark-Models](https://github.com/isHarryh/Ark-Models) 仓库的模型列表，选择下载到本地模型目录（`userData/models/`）
- 支持手动导入 zip 模型包
- ⚠️ 版权：模型资产版权归属鹰角网络，仅供个人使用，禁止商用分发

### 4.2 行为状态机

状态集合与转移：

| 状态 | 触发 | 行为 |
|------|------|------|
| Idle | 默认 | 循环待机动画，随机间隔触发基建小动作 |
| Walk | 随机/手动模式 | 在屏幕底部左右走动，到边缘转身 |
| Sit | 番茄钟专注中 | 坐下动画循环 |
| Click | 双击（戳一戳） | 播放戳一戳反应动画，完成后回 Idle |
| Drag | 按住拖动 | 跟随鼠标，松手后下落到底部 |
| Focus/Rest | 番茄钟阶段 | 专注=Sit+专注气泡；休息=活跃动作+休息气泡 |
| Remind | 截止提醒触发 | 特殊动作 + 头顶气泡显示待办标题 |

- 情绪参数（见 §6）调制状态机：心情差 → 降低 Walk 触发概率、偏向消极动作；心情好 → 高活跃度
- **心情/状态 → 动画映射**：每个干员模型的动画清单不同，按动画名关键词启发式匹配（Sit/Lie/Idle/Special/Walk 等），匹配不到则回退 Idle；映射结果在设置页可见、可手动调整（存模型目录旁的 `mapping.json`）
- 拖拽后自由落体到屏幕底部（简化物理：重力加速度 + 底部碰撞，不做弹跳）

### 4.3 点击/拖拽区分

- `pointerdown` 记录起点，移动距离 < 8px 且时长 < 300ms 判定为**点击**→ 打开待办面板
- 移动距离 ≥ 8px 判定为**拖拽** → 移动桌宠
- **双击**（300ms 内两次点击）→ 戳一戳动画；单击延迟 300ms 等待双击判定

## 5. 待办系统

### 5.1 数据模型

```ts
interface Todo {
  id: string            // uuid
  title: string
  notes?: string
  dueAt?: number        // 时间戳，可选
  priority: 'low' | 'normal' | 'high'
  done: boolean
  completedAt?: number
  createdAt: number
  source: 'manual' | 'ai'   // 创建来源（AI 对话创建的标记）
}
```

存储：`userData/todos.json`，每次变更全量写回（量级小，无需数据库）。

### 5.2 面板功能

- 分组渲染：🔴 逾期（有 dueAt 且已过且未完成）→ 📅 今天/未来（按时间升序）→ 📥 无日期
- 行内操作：勾选完成、编辑（标题/备注/截止/优先级）、删除（带撤销 toast）
- 新增：顶部输入框 + 回车，支持轻量本地时间解析（覆盖模式：`今天/明天/后天 + 上午/下午/晚上 + HH[:mm]`、`N小时/分钟后`、`周X + 时段`；解析不了则不设时间，不做开放 NLP）
- 逾期计数徽标：桌宠托盘图标/菜单显示未完成数

### 5.3 提醒调度

- 主进程每 30s 扫描未完成待办的 dueAt
- 到点（或到达"提前提醒"时刻，默认 15 分钟前，可配置）→ `Notification`（标题=待办名）+ 桌宠触发 Remind 状态气泡
- 每条待办的每种提醒只发一次（记录 `remindedAt` 内存集合）；应用启动时不补发历史提醒，只对"已逾期未完成"在面板标红

## 6. 番茄钟与情绪联动

### 6.1 番茄钟

- 默认 25min 专注 + 5min 休息，可在设置调整；面板有开始/中止按钮和今日计数
- 专注开始 → 桌宠进入 Sit；专注结束 → 通知 + 气泡"休息一下"；休息结束 → 通知 + 回 Idle
- 记录：`{date, focusCount}` 存 `userData/pomodoro.json`

### 6.2 情绪引擎

纯函数，便于单测：

```ts
function computeMood(todos: Todo[], pomodoroState: 'idle'|'focus'|'rest'): Mood
// Mood = 'happy' | 'normal' | 'gloomy'
```

- 输入：逾期未完成数 n1、今日到期未完成数 n2、今日完成数 n3
- 规则：n1 ≥ 3 或 (n1+n2) ≥ 5 → gloomy；n1=0 且 n2=0 且 n3 > 0 → happy；其余 → normal
- focus 状态强制映射为专注表现（Sit + 专注气泡），不受 mood 影响
- 输出调制：动画状态机参数（活跃度、动作偏好）+ 气泡台词库（每心情 8-12 条，随机轮换，点击/提醒/番茄事件台词独立分类）

## 7. AI 对话（在线增强）

### 7.1 配置

设置页配置 OpenAI 兼容接口：

- Base URL（预设模板：智谱 `https://open.bigmodel.cn/api/paas/v4`、DeepSeek、OpenAI，可自定义）
- API Key（存 `electron-store`，明文本地保存，UI 上掩码显示；文档中注明风险）
- 模型名（如 `glm-4.7`）

### 7.2 对话交互

- 入口：桌宠右键菜单 / 待办面板按钮 → 桌宠旁聊天气泡框
- 上下文：最近 20 条消息内存保留（不落盘）；system prompt 注入当前待办摘要和心情，AI 有角色设定（明日方舟风格的干员语气）

### 7.3 工具调用（function calling）

AI 可调用：

- `add_todo(title, due_at?, priority?, notes?)` → 创建待办，气泡确认"已添加：xxx"
- `list_todos(filter?: 'today'|'overdue'|'all')` → 返回列表摘要
- `complete_todo(title_keyword)` → 按关键词匹配完成，多个匹配时气泡让用户确认

用户说"明天下午3点提醒我交报告" → AI 解析时间（模型自身能力，时区按本地）调用 `add_todo`。

### 7.4 离线降级

- 未配置 API：聊天入口显示"未配置 AI，去设置"，其余功能全部正常
- 请求失败：气泡提示错误（超时/401/额度），不影响本地功能

## 8. 错误处理

| 场景 | 处理 |
|------|------|
| 模型 zip 损坏/格式不支持 | 加载失败弹窗引导重新下载/导入，回退到上一个可用模型；无可用模型时显示占位说明 |
| todos.json 损坏 | 尝试加载 `.bak`（每次写盘前轮换备份）；都坏则重置并告知 |
| AI 网络错误/鉴权失败 | 气泡显示具体错误，3 次连续失败后本次会话内静默禁用 AI 按钮 |
| 双开 | 单实例锁，第二个实例聚焦已有实例 |
